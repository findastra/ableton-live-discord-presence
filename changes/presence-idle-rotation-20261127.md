# Include enabled idle apps in Automatic rotation

By Astra. Implemented with OpenAI Codex, 2026-11-27.

If any connected presence app is Automatic, the helper grants all enabled apps idle-inclusive display turns. Off remains excluded. The grant expires with the display lease and never changes the saved sharing mode. Idle cards say Idle instead of claiming current work. Existing controls and page layout are unchanged. This corrects the prior activity-only rotation.
